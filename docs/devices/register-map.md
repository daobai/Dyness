# 寄存器点表（模拟设备）

保持寄存器，地址从 0 开始。模拟器 `tools/modbus/modbus_multi_device.py` 与测试 `tests/modbus/test_modbus_master.py` 共用本点表。

| 地址 | 含义 | 取值范围 |
|---|---|---|
| 0 | SOC(%) | 0 ~ 100 |
| 1 | 电压(V)×10 | — |
| 2 | 电流(A)×10（充/放方向看地址 4） | — |
| 3 | 温度(℃)×10 | — |
| 4 | 状态 | 0 待机 / 1 充电 / 2 放电 / 3 故障 |
| 5 | 告警码 | 0 无告警 |
| 6 | 心跳 | 模拟器已运行秒数（自动每秒变化） |

## 加设备

改 `tools/modbus/modbus_multi_device.py` 里的 `DEVICES` 字典，加一行就是多一台从站设备：

```python
DEVICES = {
    1: {"name": "SN001", "regs": [86, 523, 121, 312, 1, 0, 0]},  # SOC, 电压×10, 电流×10, 温度×10, 状态, 告警码, 心跳
    2: {"name": "SN002", "regs": [45, 508, 80, 298, 2, 0, 0]},
    # key = 从站地址(Unit ID)，主站读取时用 device_id 指定
}
```
